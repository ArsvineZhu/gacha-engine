# 规则依据与模型范围

资料核对日期：2026-10-11。可执行参数由 `official/gacha-games/pools/<游戏>/rule.*.json` 维护，本页记录依据与推断。`inspect PACK.json` 输出具体清单组装后的来源和假设。

## 明日方舟：终末地

机制参考来源包括 [EndfieldGacha](https://github.com/ArsvineZhu/EndfieldGacha/tree/c110ca6955d526d164da242d4b34279ea2e8f870)，包括常量、角色/武器实现和[游戏内规则转录](https://github.com/ArsvineZhu/EndfieldGacha/blob/c110ca6955d526d164da242d4b34279ea2e8f870/doc/卡池机制说明.md)。该转录记为社区依据，提供特许与武器参数；内容名单采用[独立内容目录](CONTENT.md)。

两种特许模型分别保留低稀有度概率重分配及十抽最低稀有度策略。免费十连使用基础概率与独立批次状态，不消耗普通保底和进度。武器动作通过批次标记实现十件保底，阶段奖励作为事件单独返回。

[官方重构寻访公告](https://endfield.hypergryph.com/news/4776)说明重构家族共享保底、同名复刻进度、30/60/90 一次性奖励、同名一次性 120 保底和循环 240 奖励。进度归属按公告定义；完整概率曲线仍以特许模型作为显式推断，因为公告将完整概率细节交由游戏内查看。

[重构武器说明](https://endfield.hypergryph.com/news/2651)与同次公告区分单期六星保底和同名系列定向进度。`six_miss_batches` 使用 `banner` 作用域；`featured_miss_batches`、`featured_available` 和 `requisitions` 使用 `progress_group` 作用域。换期重构池因此重置前者，并继承同名定向和奖励进度。

冬猎、寒夜幽影和艺术暴君重构武器的日期清单，依据官方公告与客户端具体池表确定成员。名单事实与概率曲线推断分别记录。票券持有、付款、有效期和库存由接入应用负责。

## 明日方舟

[官方中坚寻访调整](https://www.arknights.global/news/346)说明独立保底组及六星概率增长。中坚参考模型涵盖基础稀有度、软保底边界和初次十抽保底；低稀有度重分配及最低稀有度分配仍有模型假设。示例不覆盖其他寻访家族的限定机制和全部当期目标权重。

## 原神、星穹铁道、绝区零、鸣潮

官方来源如下：

- 原神：[捕获明光公告](https://www.hoyolab.com/article/32168979)。
- 星穹铁道：[活动跃迁公告](https://www.hoyolab.com/article/38881436)，索引正文确认角色活动跃迁保底继承。
- 绝区零：[独家频段公告](https://www.hoyolab.com/article/35773334)。
- 鸣潮：[唤取说明](https://wutheringwaves.kurogames.com/en/main/news/detail/758)和[武器活动公告](https://wutheringwaves.kurogames.com/en/main/news/detail/2662)。

上述公告未完整公开逐抽概率曲线与内部状态转移，相关参数集标为实验性参考模型。清单绑定真实角色与装备，但多数是历史/参考名单；角色示例尚未加入四星目标保底。

原神、星穹铁道、绝区零使用示例软保底曲线。鸣潮采用固定基础概率与硬保底，尚未加入未公开软保底。原神捕获明光模型以连续歪的状态表达内部概率变化；官方综合概率不能独立证明该内部状态模型。

## 异环

[官方 1.4 更新公告](https://nte.perfectworld.com/cn/article/news/gamenews/20260929/264407.html)确认 S 级黑羽、S 级弧盘罪与罚、当期 A 级角色及同名 50/120/200 外观进度，完整概率细节需在游戏内查看。

当前角色研究模型采用 S/A/资源结果投影，并设定 90 次目标保底，尚未表达棋盘位置、格子效果、额外骰子及提前外观奖励。弧盘模型独立投影为十抽批次；概率分配和第 6/8 批保底仍是实验性参数，等待完整游戏内规则核对。真实身份的依据与这些模型参数分别保存。

## 验证范围

验证覆盖单步精确质量、软/硬保底边界、跨卡池状态、独立负二项分布、50,000 次基础抽样、独立免费批次、武器奖励序列、非法规则拒绝和失败回滚。日期清单测试还覆盖活动专属内容排除、管理员不可抽和重构武器进度归属。检查入口与工具配置见 [.config](../.config/README.md)。
